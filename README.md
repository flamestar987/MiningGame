# Deep Digger — Mining Game

A responsive 2D mining game built with plain HTML, CSS, and JavaScript. No build step is required.

## Features
- Tap or click blocks to mine ores and collect them in your backpack.
- Four levels: Stone/Copper/Coal; Gold/Silver; Diamond/White Tin; Amethyst/Netherite.
- Sell ores for coins and buy mining-speed, flight-speed, and pickaxe-power upgrades.
- Responsive layout for phones and desktop browsers.

## Play locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Open the repository's **Settings → Pages**.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch `main` and folder `/(root)`, then save.
4. Wait for GitHub to show the published site URL.

Progress resets when the page is reloaded.
